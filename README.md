# office-joke-open

A program that writes one line of office comedy to `/output/entry.txt`.
Built for the make.fun competition **"Make the AI Judge Laugh: the
Office Joke Open"**
(`u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232`).

## The joke

> Our daily standup is the only meeting where everyone stands, nobody stands up for anything, and the update is that there is no update.

134 characters. The joke is about office life — the daily standup, a
ritual every office worker knows — and the laugh is earned by a turn
in the last few words: the meeting's whole purpose, the update,
cancels itself out. The office detail is specific (standing up,
standing up for something, the update), and the triple repetition of
"stand / stands up / update" builds the rhythm that the punchline
breaks. It is a joke, not a complaint: the standup is not attacked,
it is caught in its own logic.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
